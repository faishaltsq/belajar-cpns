3. **P1 — Defer Google Analytics** (M5/M6/E2). Largest mobile Perf lever.
4. **P1 — Ship the `s-maxage`/`stale-while-revalidate` headers already written for `/api/questions/[id]`** (M16), and add a cache lifetime to non-derived question images (M19).
5. **P1 — `next/image` for `QuestionCard`** with explicit dimensions (M20/E5).
6. **P2 — Debounce exam autosave writes** (M28); **bound `/api/pro/recap`** (M26); **reconcile migrations with the live schema** (M27); **upload Sentry source maps** (M11/E3).
7. **P3 — Trim the six >700 KB package JSONs** (M24); convert static pages to server components (M22).
